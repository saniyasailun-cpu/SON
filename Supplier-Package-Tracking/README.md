# ระบบบริหารจัดการพัสดุและติดตามการจัดส่งจากผู้ขาย (SSPRMS)

## ภาพรวม

ระบบนี้พัฒนาขึ้นด้วย Google Apps Script และ Google Sheets เพื่อรองรับการบริหารจัดการพัสดุจากผู้ขาย โดยแยกการใช้งานเป็นสองบทบาท:

- ผู้ขาย / ผู้ให้บริการ: ลงทะเบียนรายการพัสดุ พิมพ์ป้ายรับพัสดุ และติดตามสถานะ
- พนักงานบริษัท: ดูภาพรวมทั้งหมด จัดการพัสดุยืนยันการเข้ามา รับพัสดุ การตรวจสอบ และการรายงาน

## ข้อกำหนดที่ใช้

- Google Apps Script V8
- Google Sheets เป็นฐานข้อมูลหลัก
- HTML Service สำหรับการแสดงหน้าเว็บ
- GmailApp สำหรับส่งอีเมล
- Google Apps Script Triggers สำหรับตรวจสอบพัสดุเกินกำหนด
- ภาษาไทยเป็นภาษาที่แสดงแก่ผู้ใช้
- Timezone: Asia/Bangkok

## โครงสร้างโปรเจกต์

- `appsscript.json`: การตั้งค่า Apps Script
- `Main.gs`: จุดเข้าและ API หลัก
- `Config.gs`: การตั้งค่าระบบ
- `Database.gs`: การสร้างและจัดการชีตข้อมูล
- `Auth.gs`: ระบบยืนยันตัวตนและ Session
- `Suppliers.gs`: การจัดการผู้ขาย
- `Shipments.gs`: การจัดการรายการพัสดุ
- `Packages.gs`: การจัดการพัสดุแต่ละชิ้น
- `Tracking.gs`: สถานะและประวัติการเปลี่ยนสถานะ
- `Notifications.gs`: การแจ้งเตือนผ่าน Gmail
- `Labels.gs`: การสร้าง QR Code และป้ายพัสดุ
- `Reports.gs`: ข้อมูลสำหรับรายงานและ CSV
- `Setup.gs`: การตั้งค่าระบบและข้อมูลเริ่มต้น
- `Tests.gs`: ตัวตรวจสอบระบบแบบพื้นฐาน
- `Index.html` / `Styles.html` / `Scripts.html`: Frontend

## การติดตั้งเบื้องต้น

1. เปิด Google Apps Script ใหม่
2. สร้างโปรเจกต์เปล่า
3. คัดลอกไฟล์ทั้งหมดในโฟลเดอร์ `Supplier-Package-Tracking` ลงไปในโปรเจกต์ Apps Script
4. เปิด `setupSystem()` ใน Apps Script และรันครั้งแรกเพื่อสร้างชีตและการตั้งค่าพื้นฐาน
5. เปิด Google Sheets ที่ถูกสร้างขึ้นแล้ว ตรวจสอบชื่อชีตและหัวตาราง
6. แก้ไขข้อมูลบริษัทในหน้าจัดการตั้งค่าระบบ
7. เพิ่มบัญชีพนักงานบริษัทใน `Employees` และผูกอีเมลผู้ขายใน `Supplier_Accounts`
8. กำหนดรูปแบบและค่าเริ่มต้นของบริษัทให้ครบถ้วน

## คำสั่งสำคัญ

- `setupSystem()`: สร้างชีตและตั้งค่าเริ่มต้น
- `initializeDemoData()`: เพิ่มข้อมูลตัวอย่าง
- `runLocalValidation()`: ตรวจสอบโครงสร้างและคำสั่งสำคัญ
- `checkOverduePackages()`: ตรวจสอบพัสดุเกินกำหนด

## ข้อจำกัดและความเสี่ยง

- การตรวจสอบและแก้ไขข้อมูลพัสดุจำเป็นต้องใช้ Google Apps Script Runtime ที่มีสิทธิ์ของผู้ใช้จริง
- การส่งอีเมลให้สิทธิ์ GmailApp และต้องมีโควตาการส่งอีเมลที่เหมาะสม
- การเก็บข้อมูลใน Google Sheets มีข้อจำกัดด้านการประมวลผลและจำนวนการอ่าน/เขียน
- ระบบนี้ไม่ได้ใช้ Courier API โดยจึงไม่สามารถตรวจสอบสถานะขนส่งแบบ real-time ได้
- QR Code ไม่ได้เป็นตัวอนุญาตในการแก้ไขข้อมูลโดยตรงและยังคงต้องทำการยืนยันตัวตนก่อนเปลี่ยนสถานะ
- การตั้งค่าบัญชีจะต้องผ่านการอนุมัติจากผู้ดูแลระบบ และห้ามอนุญาตให้ผู้ขายเข้าถึงข้อมูลของผู้อื่น

## การทดสอบ

รายละเอียดการทดสอบอยู่ในไฟล์ `TESTING.md` และระบบต้องทดสอบอย่างน้อยใน Google Apps Script Runtime หลังจากเข้าสู่ระบบจริง

## การ Deploy

โปรเจกต์สามารถ Deploy ผ่าน Google Apps Script ด้วยการเลือก **Deploy > New deployment** โดยใช้ Web App และเลือกเป็น **Execute as: Me** ตามข้อกำหนดสำหรับการทำงานของผู้ใช้งานที่ไม่พึงพา กรุณาอ่านรายละเอียดเพิ่มเติมใน `DEPLOYMENT.md`
